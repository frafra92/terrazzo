# Terrazzo François

Site vitrine des tables en terrazzo coulées main (pièces uniques).

- `tables.json` : textes, prix, pieds et coordonnées de chaque table.
- `python3 build.py` : régénère `index.html`, les pages `tables/…`, `sitemap.xml` et `robots.txt`.
- Pour changer un prix : modifier `tables.json`, lancer `build.py`, envoyer les fichiers sur GitHub.
